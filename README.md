## About

- Pixel art editor using Go, emphasizing performance and modularity.
 - Implemented pixel brush canvas editing with custom color swatches, enabling intuitive pixel art creation. 
 -  image files can be saved and loaded through an integrated menu.
 - Built dynamic canvas panning and zooming features to enhance navigation and editing precision.

## Features



- Pixel brush for editing
- Saving and Loading image files
- color swatches automatically populate based on colors in image
- custom color picker
- image panning and zooming
- menu that lets you initialize new blank canvas for editing
